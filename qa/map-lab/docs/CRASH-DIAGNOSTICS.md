# Crash evidence and checkpoints

The page's **Crash diagnostics → Download diagnostic log** exports a frozen copy of the current session and the earlier retained session. Synchronous localStorage checkpoints retain source acquisition/preview stages, operation bounds, geometry settings, policy versions, source counts, build-stage boundaries, browser-reported heap usage where available, the actual WebGL renderer, errors, cancellation and context events. Geometry-report download clicks have their own checkpoint. Download checkpoints identify requests, worker activation, controller readiness, stream handoff, worker readiness, dispatch, serialization and stream cancellation/error; serialization does not certify that Chrome saved the file successfully. Repeated hydration batches are coalesced by phase; frame-by-frame logging is excluded. Source payloads and detailed generation/benchmark reports have their own downloads.

Retention and summary bounds live in [diagnostic-journal.js](../ui/diagnostic-journal.js). The event list rolls while the operation context remains separate. Retention always keeps the just-written session and selects other sessions by last activity, with deterministic ties. The log reports dropped events, oversized summaries and unavailable persistence explicitly. When storage is denied or full, the current in-memory export remains available; it cannot survive a renderer exit. Storage is local to this browser profile and origin, with no automatic upload or dataset cache. Clearing site data removes it. It cannot promise evidence through browser/OS storage corruption or power loss.

An active operation without a completion checkpoint is **incomplete evidence**, not proof of a crash: closing the tab, navigation or another still-running tab can produce that state. Reopening the same tab prefers that tab's earlier session; a new tab uses the latest retained session. Diagnostics do not resume, retry or recover any acquisition, generation or benchmark.

QA pages emit bounded `MAP LAB CHECKPOINT` console messages. [page-diagnostics.mjs](../tests/page-diagnostics.mjs) writes those messages, page errors and crashes to append-only JSONL outside the renderer. The infrastructure check also fsyncs an external checkpoint immediately before clicking the geometry-report download and after Playwright observes it. Infrastructure, large-benchmark, generator and intentional-crash checks attach the journal before navigation; their console names the unique file under ignored `.tmp/map-lab/diagnostics/`. This preserves evidence when Playwright's temporary browser profile is closed. It does not attach itself to unrelated browser sessions.

The explicit [crash experiment](../tests/crash-diagnostic.mjs) additionally writes `events.jsonl` immediately, alongside `report.json`. It records input checksum, launch, process/heap measurements, source downloads, build phases, benchmarks, target/page/context failures and shutdown. Its exclusive journal creation rejects an already-used output directory; use a fresh directory to preserve earlier evidence. Native Node termination can prevent the final report, but does not depend on a finalizer to write earlier journal entries. Chrome launch/close failures remain recorded. Files stay local and may contain source queries/URLs and errors; review them before sharing.

`diagnostic-survival-test.mjs` deliberately crashes a renderer through CDP, closes that target and opens the lab again in the same browser context. It checks the earlier local checkpoint, its exact download, the external last checkpoint/crash event, uncaught exceptions and context loss. This injected failure is separate from spontaneous crashes. `diagnostic-journal-test.mjs` covers bounds, retention, cancellation and storage denial. `diagnostic-cli-test.mjs` checks retained launch-failure evidence without opening Chrome.

Checkpoint storage and QA event capture add work between source/build/replay stages. They are diagnostic instrumentation, not a demonstration of zero overhead or an explanation of a native crash. Keep instrumented experiments separate from earlier baselines. Current spontaneous failures and byte-stability findings remain in the [review record](REVIEW-FIDELITY-2026-09-28.md).
