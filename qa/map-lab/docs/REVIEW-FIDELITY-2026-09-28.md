# Fidelity and source/render review

The source merge now retains actual observations, selects supported measurements and preserves all unique alternatives. Rendering owns estimates, interpolation, model construction, placement and visual exclusions, with a separate decision log. The [source/render contract](SOURCE-RENDER-BOUNDARY.md), [fidelity integration](FIDELITY-INTEGRATION.md), [source audit](SOURCE-FIDELITY-AUDIT.md) and in-page Help describe the implemented behavior.

Historical Chrome crashes remain monitored, but the user removed them as a commit gate. The historical byte/read discrepancies remain unexplained. The reviewed data-collection commit records the current independently verified source/fixture payloads and source/render boundary; passing checks do not diagnose those earlier failures.
